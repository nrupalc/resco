## Missing fields to collect

| Field | Why it matters |
|---|---|
| Full postal address | Required for PPA parties, notices, DISCOM applications, site documents |
| Exact registered society / association name | Required counterparty name in PPA |
| Registration certificate and number | Confirms society has legal capacity to sign |
| Bye-laws and latest committee resolution | Confirms office-bearer authority and term |
| President, secretary, treasurer names and contacts | Required for meetings, notices, signatures |
| Consumer service number(s) | Required for TSSPDCL net-metering process and billing baseline |
| 12 months of electricity bills | Required to calculate benchmark tariff, slab impact, and right sizing |
| Current sanctioned load document | Confirms 18 kWp sizing is allowed |
| Rooftop access and usable shadow-free area | Confirms system design and mounting approach |
| Structural details / roof waterproofing history | Required before installer quotation |
| Common-area electrical room / LT panel access | Required for interconnection design |
| Net-metering status | Confirms whether new bidirectional meter process is needed |

## Internal-only commercial notes

These should not be included in the first association-facing pack:

- Vendor quotation amounts.
- Bright Roof capex and payback assumptions.
- Breakeven estimates.
- Investor contribution split.
- Installer negotiation targets.

Use them only after written society consent, when installers perform the survey and Bright Roof decides whether the site clears investment approval.
