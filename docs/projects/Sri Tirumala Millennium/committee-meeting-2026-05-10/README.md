# Thirumala Rooftop Solar Proposal and Consent Pack

This folder contains the printable proposal and consent pack for Sri Tirumala Millennium Association.

## Customer-facing file

- `Thirumala-Millennium-Rooftop-Solar-Proposal-and-Consent-Pack.pdf`

This is the single PDF to print and present. It includes:

- Purpose of the pack.
- The Bright Roof proposal summary.
- Site-specific working assumptions.
- Draft PPA commercial heads.
- Document request checklist.
- Committee resolution language.
- Sign-off sheet.
- Next steps and missing company-side fields.
