# Reference Template Sources

Public, freely-available Indian rooftop-solar PPA reference templates we drew structure and standard-form clauses from. **None are adopted verbatim** — all were adapted for Bright Roof's residential-society RESCO model with retain-ownership.

## Primary sources

| Source | Where to find | What we used |
|---|---|---|
| **MNRE Model RESCO PPA for Rooftop Solar** | mnre.gov.in — published under the Rooftop Solar Programme Phase-II documentation | Overall clause order, definitions, metering, force majeure, change-in-law |
| **SECI Standard Bidding Documents (RESCO)** | seci.co.in — tender documents for group-housing / institutional rooftop RESCO tenders | Default/termination waterfall, buy-out formulae, payment security mechanics |
| **IREDA rooftop solar schemes** | ireda.in — financing documentation | Performance guarantee language, PR-shortfall credits |

## Regulatory / statutory references

| Source | Relevance |
|---|---|
| Electricity Act, 2003 | Behind-the-meter RESCO exemption; generator classification |
| CEA (Technical Standards for Connectivity of Distributed Generation Resources) Regulations, 2013 | Inverter standards, protection, synchronisation |
| CEA (Installation and Operation of Meters) Regulations | Metering accuracy, testing intervals |
| TSERC Net Metering Regulations (Telangana) — current as amended | Capacity caps, banking, settlement |
| TSSPDCL net-metering procedural orders | Application process, meter specs, approvals |
| Indian Stamp Act, 1899 (Telangana stamp rates) | Stamp duty on PPA |
| Arbitration and Conciliation Act, 1996 | Dispute resolution |
| Indian Contract Act, 1872 | General contractual law |

## Industry / NGO templates

| Source | Relevance |
|---|---|
| WRI India — rooftop solar implementation toolkit | Practical deployment guidance |
| CEEW rooftop solar policy briefs | Commercial structuring reference |

## Not to be used

| Avoid | Why |
|---|---|
| International PPAs (US PURPA, European EPC-PPA combos) | Jurisdictionally incompatible; tax, tariff, and grid structures differ fundamentally |
| Utility-scale PPAs (SECI 250 MW tenders etc.) | Scale mismatch; behind-the-meter rules don't apply |
| Free online "PPA template" downloads of unclear provenance | Quality risk; may be out-of-date with net-metering reforms |
