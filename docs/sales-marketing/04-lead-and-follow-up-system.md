# Lead And Follow-Up System

## Purpose

The sales team needs one shared tracker so leads do not disappear in WhatsApp chats.

Use Google Sheets or Airtable initially. A custom app is not needed until there is real lead volume.

## Lead Tracker Columns

| Column | Required? | Notes |
|---|---|---|
| Lead ID | Yes | Example: BR-HYD-001. |
| Society name | Yes | Exact name if known. |
| Area/locality | Yes | Example: Nacharam, Miyapur, Kondapur. |
| Approx flat count | Helpful | Use estimate if exact count unknown. |
| Approx monthly common bill | Helpful | Qualification signal. |
| Contact person | Yes | Name. |
| Contact role | Yes | Resident, secretary, president, facility manager, etc. |
| Phone | Yes | If available. |
| WhatsApp available | Helpful | Yes/no. |
| Warm intro source | Yes | Who introduced us. |
| Assigned salesperson | Yes | Srinivas, Vijay, or Kalyan. |
| Stage | Yes | Use stages below. |
| Last contact date | Yes | For follow-up discipline. |
| Next follow-up date | Yes | Must always be populated unless closed. |
| Documents received | Yes | None, recent bill, 12 months bills, society docs. |
| Rooftop access status | Helpful | Unknown, possible, permission granted, blocked. |
| Main objection | Helpful | Capture exact language. |
| Next action | Yes | Concrete action and owner. |
| Notes | Optional | Keep short. |

## Stages

Use only these stage names to keep tracking clean:

1. Lead identified
2. Contact found
3. Warm intro requested
4. First contact made
5. Interested
6. Committee meeting planned
7. Documents requested
8. Bills received
9. Survey permission requested
10. Survey permission granted
11. Proposal needed
12. PPA review
13. Won
14. Lost
15. Stalled

## Qualification Checklist

A lead is worth active pursuit if most of these are true:

- Monthly common-area electricity bill is likely above Rs. 40,000.
- Society has at least 40-50 flats, preferably 80+.
- There is a functioning committee.
- A warm introduction exists.
- Rooftop is likely accessible.
- Society has lift, pump, lighting, clubhouse, STP, or other common loads.
- The society has not already signed a competing long-term solar agreement.

## Early Disqualification Signals

Pause or deprioritize if:

- Monthly common-area bill is too low.
- No clear committee or signatory structure.
- Serious roof leakage dispute is ongoing.
- The society only wants a free quote for comparison.
- They demand exact savings before sharing bills.
- They insist on system handover after payback as a mandatory condition.

## Follow-Up Rhythm

| Timing | Action |
|---|---|
| Same day | Send thank-you message and document checklist. |
| 2 days later | Ask for bills/documents or meeting confirmation. |
| 7 days later | Ask for decision on next step. |
| 14 days later | Mark stalled unless a clear reason exists. |
| Monthly | Revisit warm but stalled leads. |
