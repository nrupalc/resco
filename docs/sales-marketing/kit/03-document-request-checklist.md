# Bright Roof Document Request Checklist

Thank you for considering a rooftop solar review with Bright Roof Power Systems.

To check whether the Bright Roof model is suitable for your society, we request the following documents and details.

## A. Electricity Details

- [ ] Last 12 months of common-area electricity bills.
- [ ] Consumer service number(s).
- [ ] Sanctioned load details, if shown separately.
- [ ] Current tariff category, if known.
- [ ] Any existing net-metering or solar application history, if applicable.

## B. Society Details

- [ ] Exact registered name of the society.
- [ ] Society registration certificate.
- [ ] Society bye-laws, if available.
- [ ] Current committee office-bearer list.
- [ ] Authorized signatory details.
- [ ] Approval process for entering into long-term utility/service agreements.

## C. Site Access Details

- [ ] Rooftop access contact person.
- [ ] Electrical room access contact person.
- [ ] Meter location access contact person.
- [ ] Preferred day/time for rooftop and electrical inspection.
- [ ] Any known roof leakage, structural, or access concerns.

## D. Optional Helpful Information

- [ ] Approximate number of flats.
- [ ] Common loads: lifts, pumps, lighting, clubhouse, STP, borewell, security room, etc.
- [ ] Previous solar proposals received, if any.
- [ ] Maintenance agency/facility manager contact.

## First Review Outcome

After receiving the above, Bright Roof will review:

1. Whether the society's electricity consumption is suitable for rooftop solar.
2. What tariff benchmark should be used.
3. Whether a rooftop/electrical survey should be scheduled.
4. What information is still missing before preparing a proposal.
