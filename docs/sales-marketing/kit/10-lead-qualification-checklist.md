# Lead Qualification Checklist

**Audience:** Internal sales team  
**Use:** Decide whether a society deserves active follow-up  
**Status:** Draft

## Quick Qualification

A lead is strong if most answers are "yes".

| Question | Yes/No | Notes |
|---|---|---|
| Is the society in Hyderabad or nearby serviceable area? | | |
| Is there a warm introduction? | | |
| Is there a committee, secretary, president, or facility manager? | | |
| Is the monthly common-area electricity bill likely above Rs. 40,000? | | |
| Are there lifts, pumps, lighting, clubhouse, STP, or other common loads? | | |
| Are there at least 40-50 flats, preferably 80+? | | |
| Is rooftop access likely possible? | | |
| Is the society open to long-term agreement discussion? | | |
| Is the society willing to share bills? | | |
| Is there no already-signed competing solar agreement? | | |

## Lead Score

| Score | Meaning | Action |
|---|---|---|
| 8-10 yes | Strong lead | Prioritize meeting and document collection. |
| 5-7 yes | Medium lead | Continue if warm intro is good. |
| 3-4 yes | Weak lead | Keep in tracker, do not spend much time. |
| 0-2 yes | Not suitable now | Mark lost or low priority. |

## Mandatory Information Before Proposal

Do not ask Nrupal for a proposal until at least these are available:

- Society name.
- Area.
- Contact person and role.
- At least one electricity bill or credible monthly bill estimate.
- Approximate flat count.
- Current stage and next action.

## Mandatory Information Before Commercial Commitment

Do not commit written pricing beyond the starting 10% message until:

- 12 months electricity bills are reviewed.
- Tariff benchmark is understood.
- Rooftop/electrical survey is complete or at least scheduled.
- Technical feasibility is checked by Srinivas/installer.
- Partners approve any stronger discount or unusual term.

## Reasons To Deprioritize

- Bill is too small.
- No decision maker is reachable.
- Society wants only a free comparison quote.
- Serious roof dispute is unresolved.
- Committee refuses to share bills.
- Society requires automatic handover as a non-negotiable condition.
- Society wants guaranteed numbers before any data sharing.
