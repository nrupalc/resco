# Sales Kit Contents

This folder contains the first usable Bright Roof sales kit.

The files are written as editable source content. After review, selected files can be converted into print-ready PDFs, DOCX files, web pages, or designed Canva/slide assets.

## Field-Ready Assets

| File | Use |
|---|---|
| `01-one-page-society-leaflet.md` | Leave-behind for apartment society committee members. |
| `02-company-profile-short.md` | Short company profile for email, print, or PDF. |
| `03-document-request-checklist.md` | Customer-facing checklist after first interest. |
| `04-bill-sharing-and-survey-consent.md` | Permission form for bills, society documents, and rooftop/electrical survey. |
| `05-faq-and-objection-replies.md` | Internal salesperson reference for common questions. |
| `06-bright-roof-vs-alternatives.md` | Customer-facing comparison against upfront purchase and handover models. |
| `07-committee-pitch-deck-outline.md` | Six-slide committee meeting deck content. |
| `08-visiting-card-content.md` | Visiting card content for Srinivas, Vijay, and Kalyan. |
| `09-email-signatures.md` | Email signature blocks for shared and individual use. |
| `10-lead-qualification-checklist.md` | Internal checklist to decide which societies deserve follow-up. |
| `../templates/lead-tracker.csv` | Spreadsheet-ready tracker headers. |
| `../templates/weekly-sales-review.md` | Weekly review template for the sales team. |

## Recommended Print Pack For First Meeting

Take only:

1. Visiting card.
2. One-page society leaflet.
3. Company profile short.
4. Document request checklist.
5. Bill-sharing and survey consent form.

Do not take:

- Vendor quote.
- Installation cost sheet.
- Investor return model.
- Partner/equity notes.
- Internal payback sheet.
