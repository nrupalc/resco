# Bright Roof Power Systems — Round 2

Two new directions only.

## K — Sunword Coral

- Reference mood: warm residential, Airbnb-like warmth
- Palette:
  - Coral `#FF5A5F`
  - Mulberry `#2F2038`
  - Sand `#FFF7F1`
  - Clay `#C76A4A`
- Idea: the sun is integrated into the wordmark itself, replacing the `O` in `Roof` and making the name feel like the logo instead of a symbol placed next to text

## L — Horizon Green

- Reference mood: clear utility, Wise-like simplicity
- Palette:
  - Solar Green `#8FD66B`
  - Deep Forest `#163122`
  - Mist `#F4F8F1`
  - Graphite `#31473B`
- Idea: the sun rises over a roofline drawn through the name, making the logo feel more infrastructural and less decorative

Both lockups use the actual brand name:

- Primary: `Bright Roof`
- Secondary: `Power Systems`
