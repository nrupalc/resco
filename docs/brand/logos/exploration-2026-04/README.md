# Bright Roof Power Systems Logo Exploration Set

Four new logo directions for review. All four stay inside the current brand system and use the actual brand name: `Bright Roof Power Systems`.

- `Dawn Navy` `#0E1E4D`
- `Roof Amber` `#F5A524`
- `Terracotta` `#C75B3C`
- `Cream` `#FAF6EE`

These are not random style swings. Each one is built around a different brand promise that matters to this business:

## G — Courtyard

File: `G-courtyard.svg`

The sun sits behind a stepped apartment-roof silhouette. This is the most explicitly residential option.

- Best for: apartment societies, signage, field material
- Signal: local, human, rooted in buildings
- Risk: less premium than the more abstract marks

## H — Meter Seal

File: `H-meter-seal.svg`

A utility-style dial ring frames a sun and roof peak. This leans into dependable infrastructure rather than lifestyle branding.

- Best for: contracts, invoices, trust-heavy sales docs
- Signal: measured, engineered, long-term
- Risk: can feel slightly formal

## I — Terrace Grid

File: `I-terrace-grid.svg`

A rising sun meets a modular roofline and solar panel grid. This is the most operationally specific of the set.

- Best for: explaining the product fast, website hero, brochures
- Signal: rooftop solar system, not generic renewable energy
- Risk: more literal, so slightly less timeless

## J — Monogram Roof

File: `J-monogram-roof.svg`

A simplified monogram built from a roofline and sun, paired with a calmer wordmark. This is the cleanest and most scalable option.

- Best for: favicon, WhatsApp avatar, long-term systemisation
- Signal: confident, restrained, ownable
- Risk: less immediately descriptive without the wordmark

## Recommendation

If the goal is **most trustworthy for apartment committees**, start with `H-meter-seal`.

If the goal is **most ownable and scalable**, start with `J-monogram-roof`.

If the goal is **most clearly residential / Hyderabad rooftop**, start with `G-courtyard`.
