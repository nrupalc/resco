## How to preview the SVGs

The SVGs open in any browser. In macOS Finder, press **space** on an SVG file — Quick Look renders it. In VS Code, install any SVG preview extension.

If you want PNG / JPEG exports (e.g. for a WhatsApp profile picture), ask and I'll render the SVGs to raster at the sizes you need.
